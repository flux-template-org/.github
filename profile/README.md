### What is Flux Theme?

Flux Theme is a collection of production-ready, multi-page Astro templates built with React and Tailwind CSS. Every template ships with real integrations, responsive layouts, and performance scores above 90+.

### Tech Stack

`Astro` `React` `Tailwind CSS` `Framer Motion` `Stripe` `Supabase` `Sanity CMS` `Vercel`

### Templates

| Template | Description |
|---|---|
| **Agency** | Studio & creative agency site with dark mode, scroll animations, and contact forms |
| **E-commerce** | Full storefront with cart, wishlist, filters, checkout, and account flows |
| **Portfolio** | Personal portfolio with project showcase and smooth transitions |
| **Blog** | Content site with multiple layouts, CMS integration, and SEO optimization |
